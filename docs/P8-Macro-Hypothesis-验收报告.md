# P8 Macro Hypothesis 验收报告

## 结论

P8 `MacroHypothesisEngine` 已完成旁路实现。它只把 P7 的冻结观察和目标期以前的推理记忆转换为结构化候选假设，不读取开奖结果、不选择模型、不调整权重、不生成生肖排名。

## 已实现

- 每期固定生成 Macro V1 的 7 类候选假设。
- `RandomFluctuation` 与 `NoMeaningfulChange` 永远进入替代解释集合。
- 假设 ID 绑定目标期、假设类型、P7 Observation 哈希和 ReasoningMemory 哈希。
- 同样输入产生相同候选、顺序、概率和 ID。
- 所有候选初始无支持证据、无反证，状态为 `Active`，评价期限冻结为目标期后 10 期。
- 无足够成熟记忆时先验为 0.50；至少 20 个成熟样本后才允许使用可靠度，并向 0.50 收缩。
- 先验严格限制在 0.10～0.90，不能从历史记忆直接获得确定判断。
- 拒绝目标期或未来训练记忆、无效哈希、错误期号关系、不可能统计和非有限可靠度。
- 极大样本计数使用浮点分母，避免整数溢出改变先验方向。

## 数据边界

P8 仅接收 `MacroObservationSnapshot` 和 `ReasoningMemorySnapshot`。它没有数据库、网络、正式预测、Gating、COUNTER、证据搜索、动作提议或写存储接口，因此不能修改正式预测结果。
