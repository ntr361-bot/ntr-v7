# V7 独立学习入口验收报告

日期：2026-09-07

模型：V7 独立学习（实验）

模型键：v7-independent-learning-v1

代码版本：independent-rank-softmax-1

## 结论

学习入口通过本地隔离验收，可以进入下一阶段的旁路接线设计。本阶段没有接入正式每日预测、界面、云端或正式 PredictionHistory，也没有训练真实数据。

两个原学习模型继续使用各自原来的生产链。此前未完成的 OnlineLearningPipeline 已从编译和测试入口排除，其对旧模型运行链的调用已撤除。对共享 AutoLearningEngine、AutoLearningTrainer 和 ModelMemory 的行为改动也已恢复。

## 已实现

- 独立 SQLite：`experiments/v7-independent-learning-v1/learning.db`。
- 独立状态、不可变预测快照、唯一学习凭证。
- 输入为 V6.5-50、V6.5-100、V6.5-全部历史的完整12生肖排名。
- 等权初始化；学习率固定为 0.05；使用 softmax 权重更新三个来源的可信度。
- 保存模型键、代码版本、Schema、输入哈希、记忆版本、生成时间、权重、分数、概率与完整排名。
- 学习审计保存实际生肖、实际名次、学习前后完整状态和时间。
- 同一期相同输入幂等；冲突输入拒绝覆盖；同期开奖重复学习不更新。
- 学习凭证写入失败时，状态更新与审计在同一事务回滚。
- 不允许目标期/未来历史、未来生成时间、遗漏前一期和缺少预测快照的学习。

## 验收证据

独立入口专项测试：23项通过，退出码0。

关键场景包括：N期记忆版本0、开奖后版本0→1、N+1使用版本1、重启保持状态、重复学习不变、冲突反馈拒绝、故障回滚后可重试、历史预测不被改写、两个旧模型的模拟记忆和历史数据库逐字节不变。

完整现有回归测试：退出码0。覆盖旧模型权重边界、V6.5自动学习、V7自动学习、PredictionHistory、每日生成、云同步、回测与映射等现有功能。

构建：.NET 10 Debug，无还原/下载；0错误。项目仍有239个既有编译警告，本阶段未扩散处理。

## 学到的内容

当前新模型只学习“三个基础模型中，哪个来源对实际生肖给出了更高的相对排名”。它更新三个来源的可信度参数。它不会学习错误的因果原因，也没有使用正式旧模型的记忆。
