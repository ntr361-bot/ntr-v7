# 6.5 波色自动学习设计

## 目标

在现有独立 `ColorEngine` 上增加开奖反馈、自适应权重、模型记忆和严格滚动验证。波色模型只优化红、蓝、绿排序，不参与生肖模型评分，也不改变生肖 TOP3/TOP6。

## 命中口径

- 主波命中：实际波色等于主波。
- 双波命中：实际波色等于主波或防波。
- 主波连续 5 期未命中触发失效分析。
- 双波连续 3 期未命中触发失效分析。
- 两个阈值独立计数、独立复位；同一期同时达到时只执行一次合并调整并记录两个原因。

## 模型与记忆

波色评分保留三个现有信号：近期频率、转换概率、当前遗漏。新增 `ColorLearningState`，持久化三个信号权重、近期主波/双波命中、连续失败计数、已学习期号和调整记录。

初始权重沿用当前比例 55%/25%/20%。每次调整单项最大 5 个百分点，单项限制 5%–85%，归一化后总和保持 100%。实际波色相对主波更有辨识力的信号得到小幅增权，误导信号减权。连续失败时基于触发窗口执行一次加强分析。

## 数据流

1. 预测前加载持久化波色记忆。
2. `ColorEngine` 使用当前波色权重生成主波、防波、排除波和每色特征快照。
3. 预测历史保存主波、防波、权重和特征快照。
4. 开奖后从特码号码转换实际波色。
5. `ColorAutoLearningEngine` 只学习一次该期反馈，更新命中序列、失败计数和权重。
6. 保存模型记忆，下一期直接复用，不重复全量训练。

## 历史验证

2023–2025 按期号从旧到新顺序训练波色记忆；预测第 N 期时只能读取 N 期以前数据。2026 按“预测→开奖→学习”顺序验证。最新 50 期验证记录补充主波、防波、实际波色、主波命中和双波命中，继续显示在智能预测历史的波色列和复盘文字中。

## 兼容与错误处理

- 老的模型记忆没有波色字段时自动使用默认权重。
- 无效号码或无法转换波色时跳过学习，不改变权重。
- 相同期号重复反馈直接忽略。
- 不增加数据库版本破坏性迁移，不改旧开奖数据，不回写未来结果。

## 验证

- 权重边界、调整幅度和总和测试。
- 主波 5 期、双波 3 期独立触发测试。
- 重复反馈幂等测试。
- 严格滚动验证无未来数据测试。
- 最新 50 期波色字段及命中状态写入测试。
- 全量既有测试和 Release 构建。
