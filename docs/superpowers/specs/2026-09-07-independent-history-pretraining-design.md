# 独立学习模型历史预训练设计

## 目标

用已经核实的2026233—2026249共17期冻结基础模型快照，对第三个独立学习模型进行可复现的历史实验预训练；不影响任何正式预测链。

## 边界

- 只写入`data/experiments/v7-independent-learning-v1`下的新实验数据库和可审核导出档。
- 不写入`PredictionHistory`、`ModelMemory`、旧AutoLearning状态、V6.5或V7预测结果。
- 每期严格执行：读取该期开奖前的三条基础排名快照→生成独立预测→读取该期真实生肖→记录一次学习收据。
- 2026244使用云端原始提交中的冻结排名，保存其UTC生成时间及提交标识；不把它伪装成本地预测记录。
- 训练产物标记`HistoricalExperiment`，不能展示为当期实时发布预测或用于正式成绩榜。

## 数据与时序

训练输入为期号、截止期、生成时间、三组完整12生肖排名、真实生肖和来源证据。17期须连续；每期预测仅使用上一期及以前的数据。输入时间不能晚于目标期开奖时间。无时区字符串不能直接用于训练；2026244以每日档案UTC字段为准。

## 实现结构

新增`IndependentLearningHistoricalTraining`，只负责验证候选样本、驱动现有`IndependentLearningModel.Predict/Learn`、输出训练清单与汇总。候选快照从本地V7数据库读取；2026244以只读云端归档JSON作为补充。训练前模型实验库必须为空，避免把历史预训练和实时实验分支混合。训练完成后导出可复现archive与报告JSON。

## 验收

1. 17期依次生成预测和学习收据，最终State.Version为17、LastIssue为2026249。
2. 原正式数据库的`PredictionHistory`与`ModelMemory`保持字节不变。
3. 相同期冻结输入可重放出相同archive；非空实验库、缺期、缺排名、目标期后生成的快照均被拒绝。
4. 2026244输入来源及UTC时间在报告中可见。
5. 训练报告包含每期实际生肖名次、Top3/Top6，以及最终三来源权重；不宣称训练样本是留出集成绩。

## 观察入口

数据中心的实验成绩榜新增“独立学习历史实验”只读入口。列表逐期显示期号、实际生肖、Top3、Top6、实际名次、命中结果、三项权重训练前后变化和快照来源；2026244明确显示云端冻结快照。入口仅读取独立实验结果，不能修改、重训或影响正式预测历史。
