# V6.5 验证完整性修复设计

## 目标

使 V6.5 四模型实验在正式运行、历史重算和云端同步时都保留严格的时间边界与可解释数据来源。

## 已批准范围

1. V6.5 自动学习首次使用前，按 2023–2025 已开奖记录与同期之前的三条 V6.5 基础快照预训练；同一实验模型记忆库只训练一次。
2. 基础模型校准只读取目标期之前已经验证的同模型、同周期预测，历史补算不能读取未来反馈。
3. 波色按号码固定，网页抓取值仅用于校验实际开奖结果；不把生肖的农历年切换错误套用到波色。
4. 云端预测继续缓存；不具备 12 生肖分项快照的档案明确不导入学习历史。同步结果和界面文案必须反映“缓存”而非“补齐预测历史”。

## 数据流

V6.5 基础 50/100/全历史快照 → 同期自动学习快照 → 开奖验证后一次性反馈。历史训练、回测和校准均以目标期为上界；生肖映射按农历年、波色映射按固定号码表。

## 约束

- 现有 V7 智能预测历史保持独立，不并入 V6.5 成绩。
- 不覆盖既有预测快照。
- 所有行为变更先以 SmokeTests 的真实数据库夹具写出失败测试。
