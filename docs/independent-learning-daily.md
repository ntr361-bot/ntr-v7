# 独立学习每日旁路接入

2026-09-07，接续 ee47fca 的入口验收。

## 调用

桌面在 AIEngine.RefreshAllPeriodPredictions 完成三个基础快照和两个原学习模型后调用 IndependentLearningDaily.TryRunDesktop。异常只进入应用日志，不中断原预测。桌面必须运行这次构建后的软件才会使用新入口。

云端在原预测与回归测试完成后，以 `--independent-daily` 启动独立进程。工作流会先跑独立学习专项测试。旁路异常标注到 Actions 摘要，原预测发布照常执行。当前变更尚未推送发布，远端还未使用该入口。

## 日常时序

只读取正式 History 和 PredictionHistory。已经保存的独立预测在开奖时间到达后学习一次；然后读取下一期的50/100/全部历史三个完整排名生成独立预测。基础快照时间必须晚于最新开奖，目标必须晚于所有已知开奖。缺失时间、缺少基础快照、未来开奖、乱序和缺口都会停止本次旁路操作。

不会重新生成已开奖期的独立预测；首次接入从当前下一期开始。电脑长时间离线造成缺口时会报告，不能悄悄拿后来的记忆补造。

## 持久化

本地数据：数据目录/experiments/v7-independent-learning-v1/learning.db。

云端独立档案：仓库 experiments/v7-independent-learning-v1/archive.json；不写入站点 daily-records 或正式运行状态。工作流只在自身运行时将该档案与本次数据一起提交。公开仓库中的该档案也会公开。

新机器从档案恢复时逐期复算预测、参数更新和审计链，最终状态必须一致；恢复失败原子回滚。已存在本地学习分支时拒绝覆盖。桌面和云端独立积累，目前未增加跨端实验记忆合并。

## 历史经验边界

已经保存的独立预测可以在真实开奖后成为学习经验。用户此前的历史预测还没有批量用于新模型训练。后续历史预训练需要核对开奖前快照和截止期；缺失快照只能进入明确标记的历史重放实验，不能伪装成实时成绩。

## 验证

专项测试共34项，覆盖原23项及档案完整恢复、拒绝覆盖已有分支、损坏档案事务回滚、每日重试、未来开奖拒绝、N→学习N→N+1、拒绝历史补造、缺少基础记录拒绝和审计留存。使用专用临时数据，没有训练生产数据库。

编译使用本地依赖和 --no-restore；测试项目及 PredictionRunner 均编译通过。完整现有回归测试退出码0。
