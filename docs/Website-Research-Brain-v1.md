# 网页研究大脑 v1（旁路）

## 目标

网页研究大脑不是“多资料投票器”。它的目标是长期研究网站里的各种资料，学习：

1. 哪些资料有可验证的信息价值；
2. 这些资料适合正向推荐、负向排除、条件判断还是号码辅助；
3. 它们长期和近期的表现是否稳定；
4. 多个栏目是否其实来自同一套内容，避免把转载误当成多份独立证据；
5. 开奖后为什么成功或失败，并把可验证经验留给后续元学习器。

v1 只做研究和经验快照，不生成、覆盖或修改正式 P25 预测。

## 第一原则：只学开奖前真实资料

旧网页页面经常同时保留历史资料与开奖结果。第一次抓到某一期旧页面时，页面内容可能已经包含开奖后的信息，即使旧解析器没有识别出来，也不能把它当作历史预测训练数据。

因此 v1 设置硬门：只有在目标期开奖日的保守训练截止时间之前已经真实冻结的快照，才允许结算为训练样本；截止时间之后抓到的内容只作为档案，不参与学习。

当前保守训练截止时间为中国时间开奖日 20:00。它不是宣称实际开奖时间，而是为了防止边界样本泄漏。后续如果数据库保存了可靠的精确开奖可用时间，应改为使用真实可用时间。

## 资料不是白名单

用户长期观察认为值得优先研究的资料，例如：

- 八肖六码
- 单双五肖
- 绝杀三肖
- 绝杀二肖
- 稳赚六肖
- 四肖八码

只作为“种子提示”，帮助解释器理解资料语义，不是固定白名单，也没有预设权重。

网站里出现的新栏目、未知栏目仍然可以进入观察池。未来的开放式发现器应自动建立稳定的 `MaterialKey`，持续追踪其历史。

## 资料理解

每条资料至少记录：

- 来源 `SourceId`
- 栏目/资料名 `MaterialName`
- 期号
- 原文与抓取时间
- 正向 / 负向 / 条件 / 未知
- 生肖 / 号码 / 混合
- 生肖顺序
- 号码集合
- 标签

当前 v1 使用规则解释器作为保底。后续可接 `IWebsiteResearchAnalyst` 的 AI 实现，让大模型负责复杂栏目语义、图片/文字资料分类和新栏目解释，但 AI 不直接给生肖任意加分。

## 经验学习

对于可直接结算的正向与负向生肖资料，模型记录：

- 长期命中率
- 最近 20 期命中率
- 最近 50 期命中率
- 对应随机基线
- 长期超额优势 `LongEdge`
- 近期超额优势
- 样本数与置信度
- 当前状态：观察、无已证实优势、近期衰退、近期增强、稳定优势

不能直接拿“六肖 60%”和“三肖 35%”比较。随机覆盖难度不同，所以必须比较相对自身基线后的超额表现。

v1 的随机基线不是固定 `N/12`，而是调用 `V65MappingService`，根据当期开奖日期对应的农历年生肖号码映射，计算该资料实际覆盖的 49 个号码概率。这样包含当年五号码生肖时会得到正确的基线。

## 去重与资料族

v1 对同一期、不同资料的生肖集合计算 Jaccard 相似度。两个资料至少共同存在 12 期，平均相似度达到 0.80 时，标记为疑似重复/转载资料族。

这只是相关性提示，不自动删除资料。后续元学习器应在资料族层面控制总证据权重，避免三个转载栏目被误认为三个独立专家。

## 暂不自动评分的资料

以下类型在 v1 中可以保存和分类，但暂不直接判优劣：

- 单双、天地、家野等条件型资料；
- 纯号码资料；
- 复杂图文、诗句、玄机图等需要语义解释的资料；
- 需要多层级理解的递进资料（如八码→六肖→四肖→二肖）。

这些要在后续分别建立正确的评价目标，不能硬塞进“生肖命中/不中”一个指标。

## 与 AI 思考能力的边界

AI 研究员适合做：

- 发现新栏目并解释它在说什么；
- 判断推荐、排除、条件、号码等语义；
- 识别栏目改名、结构变化、可能转载；
- 开奖后根据冻结证据生成错误分析；
- 提出可以被历史/前瞻验证的新假设。

AI 不应该做：

- 凭语言感觉直接说某生肖加多少分；
- 改写已经冻结的开奖前资料；
- 绕过样本门槛把新资料立即推入正式预测；
- 用开奖后的网页内容补造历史成绩。

底层经验脑必须在不接 AI 时仍然能够独立运行、复现和审计。

## 运行入口

研究分支提供手动命令：

```text
dotnet run --project PredictionRunner -- --website-brain-shadow
```

输出：

`site/data/predictions/website-research-brain.json`

该命令只读取现有网页档案和开奖历史，生成旁路研究快照，不调用 `SavePrediction`，不改正式 P25，也不改 V6/V7 正式生产结果。

## 后续阶段

### Phase A：开放式资料发现

从固定 4 个脚本升级为页面级栏目发现。对可结构化栏目建立稳定身份；保留原文、HTML 区块、抓取时间和内容哈希。

### Phase B：AI 资料理解器

实现 `IWebsiteResearchAnalyst`，让 AI 输出严格结构化的资料解释；所有解释保存版本、提示词版本和输入哈希，保证可审计。

### Phase C：经验与反思

为正向、排除、条件、号码、递进层级分别建立合适的评分；增加最长连续失效、近期漂移、来源稳定性、发布时间完整度等。

### Phase D：元学习排序器

只有积累足够前瞻样本后，才训练“一期 × 12生肖”的排序器。输入是资料价值、独立性、近期状态、位置/层级和反向证据，而不是简单出现次数。

### Phase E：前瞻验收

新版大脑先长期旁路。至少积累 50–100 个真实开奖前样本，再与旧 P25 和随机基线比较 Top3、Top6、最大连续不中、稳定性和校准情况。没有稳定优势就不接管正式预测。
