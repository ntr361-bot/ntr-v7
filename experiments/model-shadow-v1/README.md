# 模型旁路观察 v1

[观察报告](REPORT.md) · [机器统计](report.json) · [冻结档案](forward.json)

独立脚本只读取已提交的开奖历史、daily-records、runtime-state，不调用预测运行器、不访问数据库、不写正式预测。所有输出限定本目录。自动工作流在正式预测成功后及每小时检查一次，也可手动启动。

- V7：保留原结果作为基线，分别测试取消禁选、禁选分数乘0.75、频率/遗漏/重复各自转为12生肖中秩百分位后加权再软惩罚。权重固定0.55/0.45/0.1。分数不是校准概率。
- 50期：以保存的正式总分为起点，将饱和的频率、趋势替换为12生肖中秩百分位；另一候选把周期分向50收缩，可靠度为间隔样本数/(样本数+5)。固定权重0.16/0.16/0.20/0.16/0.32。保留原校准与八肖奖金，通过因子差值调整，不重新训练校准器，不把实验当作完整正式算法复现。档案保存原快照、实际变换、参数、源码哈希及历史前缀哈希。
- 100期、综合评分：原算法和原结果保留；新增低命中目标的独立候选选择。固定搜索空间为原预测、排名平移3/6/9位、排名反转。过去最多50期、至少10个已开奖样本，按前6命中率最低、前3最低、规则名称顺序选择，下一期开奖前冻结。100期使用保存的完整12生肖排名；综合评分只保存前6，剩余6生肖用固定哈希顺序补齐，该顺序不冒充正式评分。低目标是历史选择目标，不是未来低命中的保证。反选可能使命中率升高，历史选择也可能过拟合。
- 动态选择：使用V7/50期原模型的共同已开奖最近50期，前6优先、前3次之，选定模型后冻结下一期预测；记录选择依据。它用于旁路验证动态选模策略，不改首页规则。

## 口径与冻结

只能针对最新开奖之后的下一期待开正式快照生成；不会开奖后补造前瞻。相同期号不会覆盖模型预测或参数，开奖只新增独立结算结果。低目标观察晚于基础实验启动的记录，保留独立created_at。前瞻样本不足时显示“—”，不计待开为未中。比较使用所有候选共同已开奖的最多50期，也保存每模型独立统计、前6 Wilson 95%区间、最长连不中。

历史诊断逐期使用各自保存的正式特征和目标期之前开奖前缀。低目标选规则只用该目标期之前记录。回放与真实前瞻严格分开，不将旧模型事后生成的预测当作真实前瞻，不宣称校准链完整重训。样本小和多候选选择的结果不作为替换正式模型的依据。
