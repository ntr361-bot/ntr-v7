# V6 稳定版云端预测

本仓库只运行 **AI生肖预测 V6.0 稳定版**。它与 `ntr` 仓库中的 6.2 测试版完全分开，数据、预测文件、工作流和网页均不共用。

## 手机手动运行

1. 在手机浏览器打开本仓库，点击 **Actions**。
2. 选择 **Run V6 Stable Prediction**。
3. 点击 **Run workflow**。
4. 保持 `refresh_data=true`，系统会先读取最新开奖，再补齐遗漏期数并生成下一期。
5. 运行成功后打开“云端智能流水账本”的预测页面查看全部 V6 结果。

`issue` 可指定一期；`start_issue` 控制从哪一期开始检查遗漏；`force=true` 会覆盖已存在文件；`dry_run=true` 只检查，不保存。

## 自动运行

工作流每天按北京时间 21:45、22:00、22:15 尝试更新。GitHub Actions 的 cron 使用 UTC 时间，当前三个时间分别写为 `13:45`、`14:00`、`14:15` UTC。多次运行不会生成重复记录，同一期同一分析周期只保留一条。

每次运行会：

- 抓取并校验真实开奖记录。
- 从 `2026197` 起检查和补齐遗漏预测。
- 使用每一期之前已经开奖的数据生成当期预测，避免使用未来数据。
- 为已经开奖的预测逐项写入命中或未命中结果。
- 生成下一期 V6 预测并提交到私有仓库，智能流水通过安全的服务器接口显示结果。

## 常见问题

- **工作流没有运行**：确认 Actions 已启用，并查看运行日志中的明确错误。
- **没有写入权限**：仓库 Settings > Actions > General 中允许 Actions 读写仓库内容。
- **预测文件已存在**：正常情况下会跳过；需要重新生成时选择 `force=true`。
- **历史数据缺失**：查看“Refresh latest draw data”步骤，确认开奖源已经更新。
- **网站仍显示旧数据**：打开智能流水预测页，点击“刷新结果”。
- **执行成功但页面没更新**：确认私有仓库已生成新 JSON，再刷新智能流水页面。

不需要配置账号密码或 Token。仓库使用 GitHub 自带的 `GITHUB_TOKEN` 完成提交和 Pages 发布。
