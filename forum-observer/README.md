# 论坛生肖观察器（安全基础版）

本项目是**可运行的统计与冻结内核**，不是已打通论坛的全自动爬虫。当前没有经过核实的论坛API、作者详情接口、开奖时间和2026号码生肖映射，**不能凭空编造采集器或声称已自动抓到25份**。

## 运行

```bash
python -m unittest discover -s tests -v
python -m forum_observer.cli --input input-example.json --output out
# 确认有25份以上、15:10且开奖前，再添加 --freeze；禁止用演示数据正式冻结
```

真实数据放到 `input/current.json`，结构参照 `input-example.json`。`leaderboard_authors` 必须是有来源依据的榜单作者集合，旧截图仅作候选名单；不能作为实时榜单证据。`works` 必须包含可核实的作者、玩法、原文、原始URL、发布时间及期号。`draw_at` 必须是实际已核实的开奖截止时间，不能沿用演示时间。所有时间需包含时区。无证据的数据不能输入。

## 已实现

- 验证期号、作者、组别、玩法、链接、证据、开奖前发布时间。
- 同作者同玩法去重；按严格3:2筛选可用样本，最少15+10。
- 生肖推荐与排除集合归一化；每份作品总票数为1；12肖完整排名与Top1/3/6。
- 不足样本只生成状态，不伪造正式冻结；开奖后禁止冻结；`xb` 不覆盖已冻结JSON；附SHA256。
- GitHub Actions每日20:00（北京时间）运行测试与已有输入的校验；可下载状态产物。

## 尚未实现 / 需要真实接口后接入

1. 论坛实时榜单、作者主页、帖子与评论区采集适配器（应先确认站点许可与真实API或页面结构）。
2. 自动发现最新未开奖期号及真实开奖截止时间，自动保存逐作者检查进度、动态榜单比对。
3. 号码、波色、头尾转换：必须先核实2026年生肖号码映射，不可猜。
4. 自动报告Markdown、开奖后结算、账本同步OIDC：需要现有合法接口与凭据配置。
5. 生产环境持久化：Actions临时文件系统不等于可靠数据库；冻结文件应保存到受保护持久存储，禁止自动覆盖。

**注意**：GitHub Actions的cron是近似调度，可能延迟，不能保证20:00精确开始或20:30完成。仅有定时workflow不代表论坛采集已自动化。

**不修改D1、不运行V7、不覆盖任何冻结预测。**

## V2 增强（2026-10-08）

- `forum_observer.collector`：公开 JSON 数据源采集适配器；自动读取期号、榜单前20、作者作品，逐作者保存 `checkpoint.json`，失败记录具体原因；仅访问配置白名单中的 HTTPS 主机。
- `forum_observer.auto`：自动执行入口，输出 `status.json`、`report.md` 或明确的 `collection-error.json`。
- `forum_observer.settlement`：开奖后核对冻结 SHA256 并独立生成不可覆盖的 `settlement.json`。
- `collector-config.example.json`：**仅是接口结构示例，example.org 不是真实论坛接口**。需通过公开合法的真实接口验证后才能投入采集；不自动猜测接口或绕过访问限制。
- GitHub Actions 每晚执行自动入口（有真实配置时）；配置缺失明确失败并上传日志，绝不假报成功。

运行：`python -m forum_observer.auto --config collector-config.json --out out`。

**尚未完成**：真实论坛 API 适配、自动从评论/图片识别预测、当期号码波色映射、跨 Actions 运行持久化、生产冻结的持久化上传、账本 OIDC 同步。当前只在受控模拟数据上验证自动采集链，不能声称已抓取281期。

## V3 安全增强
- 实时榜单失败时使用历史截图中的20名作者**仅作候选线索**继续逐人采集；无法验证实时榜单归属时强制观察状态，禁止正式排名与冻结。
- HTTPS 采集拒绝跨站重定向；作品发布时间不能在未来。
- `freeze_enabled` 默认关闭；仅在已配置**跨运行不可覆盖的持久化存储**并核实开奖时间后开启。GitHub Actions 的 artifact 不能代替冻结数据库。
- 本包不包含已验证的论坛 API，配置文件中的 `example.org` 仅为占位。

## V3.1 动态网页采集
- 论坛没有公开 JSON API 时，`forum_observer.page_collector` 使用 Chromium 的无头渲染结果读取页面 DOM。
- 默认配置指向 `https://x5k1pok.11852.com:8443/#/forum`，只生成带原文、作者、时间和图片证据的观察结果。
- 页面观察不会自动冒充实时榜单，也不会自动冻结预测；必须另行核实作者榜单和开奖截止时间。
